# Changelog

## 1.0.0 - 2026-10-28 - initial publication

- First public version of Lutetia: the recipe (`recipe/recette.toml`) and its inputs, the clean package (`package/`), the package with deliberate errors (`package-with-errors/`), and the documentation.
- 1 302 data objects of 67 types in the clean package (RESQML 2.2, EML 2.3, WITSML 2.1, PRODML 2.3); 1 341 in the variant with errors. See `docs/inventory.md`.
- Produced with the energyml CLI 0.1.0 (`recipe/energyml-version`).
- Known gaps: the steps `h2`, `grilles-craie` and `couleurs` are on hold; E-05 is not written; the data are under CC BY 4.0, the BSS data (Licence Ouverte 2.0) modified for this example (see `LICENSE-data` and `docs/sources.md`).
- Zenodo DOI: [10.5281/zenodo.23730912](https://doi.org/10.5281/zenodo.23730912) (every version: [10.5281/zenodo.23730911](https://doi.org/10.5281/zenodo.23730911)).
